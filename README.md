# Habilidades TFJA

Plataforma de capacitación para el personal del Tribunal Federal de Justicia Administrativa.

## Tecnologías

- Next.js
- React
- TypeScript
- Tailwind CSS
- MongoDB

## Ejecución local

Instala las dependencias:

npm install

Ejecuta el servidor de desarrollo:

npm run dev

Abre en el navegador:

http://localhost:3000

## Compilación de producción

npm run build

## Variables de entorno

El proyecto utiliza un archivo .env.local para la configuración local.

Este archivo no debe subirse al repositorio.

## Despliegue

El proyecto puede desplegarse en Vercel mediante la rama principal main.
